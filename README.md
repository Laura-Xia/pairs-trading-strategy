# Pairs Trading Strategy Using Cointegration

This project builds a rolling z-score pairs trading strategy using S&P 500 stock price data from Yahoo Finance.

The project includes:
- Data loading and cleaning
- Correlation and cointegration testing
- Hedge ratio estimation
- Spread and rolling z-score construction
- Out-of-sample backtesting
- Transaction costs
- Performance evaluation
- Sensitivity analysis
- Portfolio-level cumulative returns
